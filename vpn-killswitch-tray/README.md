# vpn-killswitch-tray

Пользовательское приложение для системного трея поверх `vpn-killswitch`.

Назначение:

- показывать текущий статус VPN/lock/bypass в системном трее;
- давать простой способ добавить или удалить домен;
- вызывать существующий CLI `vpn-killswitch`, не дублируя системную логику.

Полное описание: [TZ.md](TZ.md).

## Возможности

- показывает состояние VPN/lock/bypass в системном трее;
- запускает диагностику `test`, `install-check`, `resolve`;
- включает/выключает/обновляет lock через `pkexec`;
- показывает общий список доменов bypass/lock;
- редактирует списки доменов bypass/lock в одном окне;
- после изменения домена сразу применяет правила.

## Срочные планируемые правки

- сохранение изменений в редакторе не должно много раз спрашивать пароль: одно нажатие «Сохранить» должно запускать не больше одного `pkexec`;
- редактор должен уметь добавлять в bypass не только домены, но и явные IPv4-адреса/диапазоны:
  - `93.184.216.34`
  - `93.184.216.0/24`
  - `93.184.216.10-93.184.216.20`
- после сохранения правила должны применяться в рамках той же привилегированной операции, без отдельного второго запроса пароля.

## Требования

- установленный и настроенный `vpn-killswitch`;
- Linux с графическим окружением и системным треем;
- `pkexec` для изменяющих действий;
- `yad` для редактора доменов.

Если `pkexec` отсутствует, приложение остаётся индикатором только для чтения. Если нет `yad`, редактор доменов отключается.

## Сборка

```bash
go build -buildvcs=false -o vpn-killswitch-tray ./cmd/vpn-killswitch-tray
```

## Запуск вручную

```bash
./vpn-killswitch-tray
```

Для проверки версии:

```bash
./vpn-killswitch-tray --version
```

## Установка для текущего пользователя

```bash
./scripts/install-user.sh
```

Скрипт собирает бинарник и устанавливает:

```text
~/.local/bin/vpn-killswitch-tray
~/.config/autostart/vpn-killswitch-tray.desktop
```

После этого приложение будет стартовать при входе в графическую сессию.

Если автозапуск не нужен:

```bash
./scripts/install-user.sh --no-autostart
```

## Ежедневное использование

- иконка в трее показывает текущее состояние;
- «Обновить статус» перечитывает текущее состояние;
- «Применить сейчас» запускает `vpn-killswitch enforce tray`;
- меню Lock управляет текущим lock-состоянием;
- «Домены...» открывает редактор с двумя списками: bypass и lock;
- после нажатия «Сохранить» приложение сравнивает старый и новый состав списков, добавляет/удаляет нужные домены и применяет правила;
- меню «Диагностика» запускает read-only проверки.

## Решение проблем

Если иконка серая и статус `vpn-killswitch not found`, проверь:

```bash
which vpn-killswitch
/usr/local/sbin/vpn-killswitch status --json
```

Если изменяющие пункты меню отключены, проверь наличие `pkexec`:

```bash
which pkexec
```

Если редактор доменов отключён, установи `yad`.

Если приложение не стартует после входа в систему, проверь desktop entry:

```bash
cat ~/.config/autostart/vpn-killswitch-tray.desktop
```
