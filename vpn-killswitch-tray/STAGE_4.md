# Этап 4: Изменяющие действия и формы доменов

Этап 4 добавляет контролируемые действия через `pkexec`.

## Реализовать

- Команду «Применить сейчас».
- Команду «Включить lock».
- Команду «Выключить lock».
- Команду «Обновить lock».
- Форму добавления домена в bypass.
- Форму добавления домена в lock.
- Форму удаления домена из bypass.
- Форму удаления домена из lock.
- Автоматическое применение после успешного изменения конфига.
- Отключение изменяющих пунктов меню, пока выполняется команда `pkexec`.

## Механизм форм

- Использовать `yad` для единого редактора доменов.
- Если нет ни одного механизма форм, отключать действия с доменами и объяснять причину в меню/логе.

## UX `pkexec`

- Отмена ввода пароля не считается системной ошибкой.
- Писать отмену действия в лог.
- Писать ошибку команды в лог.
- Обновлять статус сразу после каждой изменяющей команды.

## Готово, когда

- Домены можно добавить/удалить/перенести между списками без запоминания CLI-синтаксиса.
- Приложение никогда не запускает несколько действий через `pkexec` одновременно.
- Приложение не показывает `uninstall`, `purge`, очистку старых артефактов или произвольные shell-команды.
