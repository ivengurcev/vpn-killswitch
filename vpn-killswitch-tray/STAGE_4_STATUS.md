# Статус этапа 4

Изменяющие действия и формы доменов этапа 4 реализованы.

## Реализовано

- Команда «Применить сейчас» через `pkexec vpn-killswitch enforce tray`.
- Команды `lock enable`, `lock disable`, `lock refresh`.
- Просмотр общего списка доменов bypass/lock из tray.
- Единый редактор доменов через `yad`.
- Сравнение старого и нового состава списков при сохранении.
- Команды изменения списков bypass/lock через `pkexec`.
- Автоматическое применение правил после изменения домена.
- Блокировка изменяющих пунктов меню, пока выполняется действие.
- Мягкая обработка отмены `pkexec`.
- Уведомления об успехе и ошибке.
- Немедленное обновление статуса после изменяющей команды.
- Увеличенный таймаут для пользовательских действий, чтобы `pkexec` и формы не обрывались через 3 секунды.

## Тесты

- Построение `pkexec`-команд для изменения конфига.
- Построение `lock enable` с actor `tray`.
- Распознавание отмены `pkexec`.
- Чтение и форматирование списков доменов из TOML-конфига.
- Полный `go test ./...` проходит.
- Бинарник собирается.
