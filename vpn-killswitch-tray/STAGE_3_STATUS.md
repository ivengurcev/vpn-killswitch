# Статус этапа 3

Интерфейс в трее только для чтения этапа 3 реализован.

## Реализовано

- Настоящая точка входа systray.
- Переключение иконки по состоянию.
- Обновление подсказки и строки статуса в меню.
- Цикл опроса состояния.
- Ручное обновление.
- Диагностическое меню только для чтения:
  - запуск `test`;
  - запуск `install-check`;
  - запуск `resolve`.
- Пункты меню «О программе» и «Выход».

## Не входит в этап 3

- Изменяющие действия.
- Формы добавления/удаления домена.
- Выполнение команд через `pkexec`.
- Упаковка и автозапуск.

## Проверка

- `go test ./...` проходит.
- Бинарник собирается с `getlantern/systray`.
- Поведение приложения в трее во время работы ещё нужно проверить вручную в графической сессии.
