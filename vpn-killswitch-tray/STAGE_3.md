# Этап 3: Интерфейс в трее только для чтения

Этап 3 создаёт первое видимое приложение в трее без изменения системного состояния.

## Реализовать

- Точку входа процесса приложения в трее.
- Состояния иконки:
  - зелёная/`ok`
  - красная/`locked`
  - жёлтая/`warning`
  - серая/`offline`
- Обновление подсказки.
- Строку статуса в меню.
- Цикл опроса состояния.
- Ручное обновление.
- Диагностические действия:
  - запуск `test`;
  - запуск `install-check`;
  - запуск `resolve`.

## Ограничения

- Изменяющих действий ещё нет.
- `pkexec` на этом этапе не нужен.

## Готово, когда

- Приложение запускается от обычного пользователя.
- Приложение показывает текущее состояние `vpn-killswitch`.
- Приложение обновляется после периодического и ручного обновления.
- Приложение остаётся полезным, даже если доступны только иконка и меню.
