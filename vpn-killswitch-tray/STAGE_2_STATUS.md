# Статус этапа 2

Внутренняя логика приложения в трее этапа 2 реализована.

## Реализовано

- Go-модуль и стартовая команда.
- Загрузчик настроек со значениями по умолчанию.
- Поиск команды `vpn-killswitch`.
- Исполнитель команд с таймаутом.
- Парсер для `vpn-killswitch status --json`.
- Нормализованная модель состояния приложения в трее.
- Определение инструментов `pkexec`, `yad`, `zenity`, `kdialog`.
- Лог приложения в трее.
- Внутренний клиент, который запускает `vpn-killswitch status --json`.

## Тесты

- Значения по умолчанию и переопределения настроек.
- Парсинг JSON статуса.
- Нормализация состояния.
- Ограничение частоты повторяющихся ошибок.
- Аргументы и парсинг внутреннего клиента.
