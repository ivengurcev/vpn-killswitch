# Этап 2: Внутренняя логика приложения в трее

Этап 2 строит логику без интерфейса, которую можно тестировать без запуска системного трея.

## Реализовать

- Go-модуль и структуру пакетов.
- Загрузчик настроек со значениями по умолчанию.
- Поиск команды `vpn-killswitch`.
- Исполнитель команд с таймаутом.
- Парсер для `vpn-killswitch status --json`.
- Нормализованную модель состояния:
  - `offline`
  - `ok`
  - `locked`
  - `warning`
  - `error`
- Лог приложения в трее.
- Определение доступных инструментов:
  - `pkexec`
  - `yad`
  - `zenity`
  - `kdialog`

## Тесты

- Парсинг JSON статуса.
- Нормализация `status` в состояние приложения в трее.
- Повторяющиеся ошибки не спамятся 60 секунд.
- Определение отсутствующих инструментов и режима ограниченной работы.

## Готово, когда

- `go test ./...` проходит.
- Внутреннюю логику можно проверить без запуска иконки в трее.
- Отсутствующий `vpn-killswitch` даёт состояние `offline`.
