# Этап 5: Упаковка, автозапуск и приёмка

Этап 5 делает приложение в трее удобным для ежедневного запуска.

## Реализовать

- Инструкции сборки.
- Пример desktop entry-файла.
- Инструкции автозапуска.
- Опциональный install-скрипт.
- Раздел использования в README.
- Раздел решения проблем.

## Цель автозапуска

```text
~/.config/autostart/vpn-killswitch-tray.desktop
```

## Приёмочные проверки

- Приложение стартует после входа в систему.
- Приложение находит `/usr/local/sbin/vpn-killswitch`.
- Приложение пишет лог в `~/.local/state/vpn-killswitch-tray/tray.log`.
- Приложение показывает корректное состояние после подключения/отключения VPN.
- Приложение показывает смену состояния через иконку и меню.
- Приложение умеет добавить/удалить домены bypass.
- Приложение умеет добавить/удалить домены lock.
- Приложение остаётся полезным в режиме только для чтения, если `pkexec` недоступен.

## Готово, когда

- Приложением можно пользоваться ежедневно без открытия терминала для частых изменений доменов.
- Терминал остаётся нужен только для установки, удаления и очистки старых артефактов.
